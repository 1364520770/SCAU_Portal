# 小程序码放这里（方案 A）

把微信里保存的小程序码 / 二维码图片放进这个目录，然后在 `data.js` 的 `miniprograms` 里写相对路径：

```js
{
  id: 'mp-zijing-chuxing',
  name: '紫荆出行',
  qrcode: 'assets/miniprogram/zijing-chuxing.png'   // ← 填这一行
}
```

## 怎么给「紫荆出行 / 欢洗有你 / 紫荆e卡」拿到小程序码

这三张卡片现在走的是「复制名称 + 微信搜索」的兜底，卡片上的「怎么进入？」按钮里也写了步骤。想升级成扫码进入：

1. 手机微信里打开该小程序；
2. 右上角「···」→ 分享 → **保存小程序码 / 生成二维码**到相册（有些小程序会把码放在首页或「我的」页面）；
3. 把图片传进本目录，文件名用英文，例如 `zijing-chuxing.png`；
4. 在 `data.js` 里对应条目的 `qrcode` 填上路径，刷新页面即可。

## 建议

- 用 PNG，尺寸 400~600px 就够（文件小、加载快）。
- 从微信保存的图里只保留中间的码，裁掉多余聊天截图部分，页面上更好看。
- 电脑端用手机微信「扫一扫」扫码；手机端在微信里打开本页后「长按」图片 → 「识别图中二维码」。

## 想要「一点就打开小程序」？

那是 `README.md` 第四章的方案 B（微信 URL Link），链接不放在这个目录，而是写在 `data/url-links.js` 里。
生成脚本在 `server/generate-url-link.js`，但它需要**目标小程序自己的 AppID + AppSecret**，
所以只能由小程序运营方生成好链接给你。
